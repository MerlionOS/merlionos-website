## At a Glance

- **Preemptive multitasking** with per-process page tables
- **SMP support** up to 16 CPUs
- **Virtual filesystem** with /dev, /proc, /tmp
- **IPC** via channel-based message passing
- **Syscall ABI** (int 0x80) with write, exit, yield, getpid, sleep, send, recv
- **ACPI** power management (shutdown, reboot)
- **PCI** bus enumeration
- **Networking** stack: IPv4, UDP, loopback, ARP, ICMP

## Quick Start

```sh
# Prerequisites: Rust nightly + QEMU
rustup component add rust-src llvm-tools --toolchain nightly
cargo install bootimage
brew install qemu  # macOS

# Build and run
git clone https://github.com/MerlionOS/merlion-kernel.git
cd merlion-kernel
make run
```
